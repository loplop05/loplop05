</div>

<tr>
<td width="33%" valign="top">

**🖥️ ElectroPOS Pro**
Full retail POS for Apple resellers — C# WinForms + SQL Server + a Flask ML microservice doing sales forecasting (Prophet/XGBoost), FBT recommendations (FP-Growth), and RFM customer clustering.

</td>
<td width="33%" valign="top">

**💻 Laptop Recommender**
Flask app matching Jordanian shoppers to laptops in JOD. Hard filtering → weighted scoring → generated reasoning, backed by a scraped 3-retailer SQLite dataset.

</td>
<td width="33%" valign="top">

**😴 Drowsiness Detection**
Deep learning classifier reading driver eye-state from a custom image pipeline — safety-critical inference on a budget.

</td>

</td>
